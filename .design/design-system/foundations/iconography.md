# Iconography

## Purpose

Icons are drawn like marks made with a ruling pen.

## Rules

- Sixteen unit grid, 1.5 unit stroke, square caps, mitred joins, no fill.
- Icons inherit the text color.
- Decorative icons are hidden from assistive technology; a lone icon in a control is named by the control.
- Eight marks exist; add new ones on the same grid.

## Do and do not

- Pair an icon with a text label.
- Never use an icon set from outside the system.
