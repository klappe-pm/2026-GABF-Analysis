# Saved views

Saved views: planned. Views a visitor saves live only in their own browser.

## `header`

Where: top of the page.

- `title`: Saved Views
- `lede`: Views you saved on this device. They stay in this browser; nothing is sent or synced.

## `save`

Where: the save control on any filterable page.

- `button`: Save This View
- `name_label`: Name This View
- `name_placeholder`: For example, Hazy IPA in Colorado
- `saved`: View saved.

## `item`

Where: each saved view in the list.

- `open`: Open
- `rename`: Rename
- `delete`: Delete
- `copy_link`: Copy link
- `link_copied`: Link copied.
- `filters_summary`: {{count}} Filters on {{page_title}}

## `empty`

Where: in place of the list when nothing is saved.

- `title`: No saved views yet.
- `body`: Set Filters on any page, then choose Save this view.

## `storage_error`

Where: in place of the list when the browser blocks storage.

- `body`: This browser is not keeping saved data, so views cannot be saved here. Copy the page link instead; it carries the filters.
