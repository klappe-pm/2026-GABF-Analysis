# Charts

Chart chrome shared by every chart: toolbox, table view, tooltips, and units.

## `toolbox`

Where: the small toolbox at the top right of every chart.

- `save_png`: Save as PNG
- `data`: View Data
- `data_close`: Close
- `data_refresh`: Refresh
- `reset`: Reset

## `table_view`

Where: the disclosure under every chart.

- `summary`: Table view

## `tooltip`

Where: hover and focus tooltips on chart marks.

- `value`: {{name}}: {{value}}
- `value_with_unit`: {{name}}: {{value}} {{unit}}
- `scatter`: {{name}}: {{x}} entries, {{y}} breweries

## `units`

Where: series names, axis names, and value columns.

- `medals`: Medals
- `points`: Points
- `entries`: Entries
- `entrants`: Entrants
- `breweries`: Breweries
- `per_million`: Per Million Residents
- `per_100b_gdp`: Per $100B Real GDP
- `entries_per_medal`: Entries per Medal
- `revenue`: Revenue (E)
- `arr`: ARR (E)

## `legend`

Where: legends on medal charts and stacked charts.

- `gold`: Gold
- `silver`: Silver
- `bronze`: Bronze
- `classic`: Classic Style Categories
- `special`: Special Categories
- `other`: Other
- `breweries_entering`: Breweries Entering
- `winning_breweries`: Winning Breweries

## `table_columns`

Where: the generic label column in a chart's table view.

- `name`: Name
- `value`: Value
