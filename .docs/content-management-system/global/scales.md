# Scales

The range scale that places a beer's ABV or IBU inside its style's minimum to maximum, as on a judging scoresheet.

## `range`

Where: beside every published ABV and IBU on beer pages and in the style guide.

- `style_range`: Style range {{min}} to {{max}}
- `inside`: Inside the style range, {{min}} to {{max}}.
- `below`: Below the style range, {{min}} to {{max}}.
- `above`: Above the style range, {{min}} to {{max}}.
- `no_range`: No style range is defined for this category.
- `not_published`: Not published. No source gives this value, so the scale shows the style range only.
- `source`: Range: {{source}}
