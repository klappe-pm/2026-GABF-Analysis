## style-context

As category context only, the [Brewers Association guideline](https://www.brewersassociation.org/edu/brewers-association-beer-style-guidelines/) for Field Beer asks for vegetable aroma and flavor, subtle to intense, not masked by hops, with IBU and ABV varying with the base style; the same guidelines class coconut as a vegetable. A coconut porter therefore fits the category.
