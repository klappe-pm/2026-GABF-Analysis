## style-context

As category context only, the [Brewers Association guideline](https://www.brewersassociation.org/edu/brewers-association-beer-style-guidelines/) for Smoke Beer covers any style incorporating smoke, from very light to black, and asks for a balance between the base style's character and the smoky properties; for smoked lagers, any phenolic notes should come from the smoke, not the yeast. A smoked helles that moves from smoke to malt sweetness matches that balance as described.
