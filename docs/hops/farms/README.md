# hop-farms

State by state overview of the US hop farms recorded for the hops layer of the medal beer analysis. Each farm has its own page, and the data lives in `data/reference/hop-farms.csv`, `data/reference/hop-farm-varieties.csv`, `data/reference/hop-merchants.csv` and `data/reference/hop-farm-gaps.csv`.

## method

Every field is copied from a named source. Variety names are written exactly as the source prints them, trademark marks included, so a later step can normalize them to canonical varieties. A farm is never assumed to grow a variety without a source. Where a page could not be opened and a fact comes from a search result summary, the note says so.

## counts-against-published-totals

68 farms are recorded. No source publishes a complete grower list or a per state grower count: USDA NASS reports acreage and production for Idaho, Oregon and Washington only, a trade newsletter puts the Pacific Northwest at about 70 farms in 2023, the Oregon Encyclopedia says fewer than 30 families grow hops commercially in Oregon, and Hop Growers of Michigan reports more than 20 growers statewide. The gaps file lists every source checked and every list that could not be read.
