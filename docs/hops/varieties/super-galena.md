# super-galena

Super Galena is a hop variety from the United States, proprietary, from Hopsteiner breeding program. Its published alpha acid range is 13 to 16 percent.

## identity

| Field | Value |
|---|---|
| Origin | United States |
| Breeder or owner program | Hopsteiner breeding program |
| Trademark | Super Galena (trademark, per NASS) |
| Proprietary or public | proprietary |
| Year released | not published |
| Parentage | 9801 crossed with USDA 19058m (Hopsteiner experimental hop 99008) |
| Published use | not published |
| Alpha class | medium (8 to 14 percent) |

Also published as: Super Galena Hopsteiner 99008.

## aroma

As published by Hopsteiner data sheet: "grass, spicy"
