# styrian-golding

Styrian Golding is a hop variety from Slovenia, with proprietary status not published, from Slovenia (Hopsteiner sheet describes the Celeia line; the institute is not named on the sheet). Its published alpha acid range is 4 to 7 percent.

## identity

| Field | Value |
|---|---|
| Origin | Slovenia |
| Breeder or owner program | Slovenia (Hopsteiner sheet describes the Celeia line; the institute is not named on the sheet) |
| Trademark | none found |
| Proprietary or public | not published |
| Year released | not published |
| Parentage | Styrian Golding (Celeia) is a triploid cross between Savinjski Golding and 105/58, itself a cross between Aurora and a Slovenian wild hop (Hopsteiner) |
| Published use | not published |
| Alpha class | low (below 8 percent) |

Also published as: Styrian Goldings, Styrian Golding Celeia, Celeia, Savinjski Golding.
