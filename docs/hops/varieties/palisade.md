# palisade

Palisade is a hop variety from the United States, proprietary, from Yakima Chief Ranches. Its published alpha acid range is 5.5 to 9.5 percent.

## identity

| Field | Value |
|---|---|
| Origin | United States |
| Breeder or owner program | Yakima Chief Ranches |
| Trademark | Palisade (registered, per NASS and the John I. Haas sheet) |
| Proprietary or public | proprietary |
| Year released | not published |
| Parentage | Open pollination |
| Published use | aroma (aroma) |
| Alpha class | medium (8 to 14 percent) |

Also published as: Palisade YCR 4, YCR 4.

## aroma

As published by John I. Haas variety sheet: "Mild, pleasant aroma"
