# eureka

Eureka is a hop variety from the United States, proprietary, from Hopsteiner breeding program. Its published alpha acid range is 17 to 19.9 percent.

## identity

| Field | Value |
|---|---|
| Origin | United States |
| Breeder or owner program | Hopsteiner breeding program |
| Trademark | Eureka! (trademark, per NASS and Hopsteiner) |
| Proprietary or public | proprietary |
| Year released | not published |
| Parentage | Apollo crossed with Merkur (Hopsteiner experimental hop 05256) |
| Published use | not published |
| Alpha class | high (14 percent and above) |

Also published as: Eureka!, Eureka Hopsteiner 05256.

## aroma

As published by Hopsteiner data sheet: "black currant, dark fruits, strong herbal notes, pine tree"

## gaps

- Identity, year_released: The Hopsteiner data sheet publishes no release year.
- Chemistry, myrcene, humulene, caryophyllene, farnesene not published. Oil components: the Hopsteiner data sheet publishes only the beta caryophyllene to humulene ratio (0.45 to 0.55) and linalool (0.6 to 1.0 percent of oil), not myrcene, humulene, caryophyllene or farnesene shares.
