# ramosa

Ramosa is a hop variety from the United States, proprietary, from Segal Ranch (Yakima Valley, Washington). It was released in 2026. No alpha acid range was published on any page that could be read.

## identity

| Field | Value |
|---|---|
| Origin | United States |
| Breeder or owner program | Segal Ranch (Yakima Valley, Washington) |
| Trademark | Ramosa (trademark symbol used in the release) |
| Proprietary or public | proprietary |
| Year released | 2026 (Announced March 10, 2026 under the former experimental name D55.) |
| Parentage | not published |
| Published use | not published |
| Alpha class | not published |

Also published as: D55, Ramosa D55.

## aroma

As published by Segal Ranch release (Washington Beer Blog): "pineapple, mango, and fresh-cut melon"

## acreage

NASS names no line for this variety in the National Hop Report, so no state acreage is published for it.

## gaps

- Identity, parentage: The Segal Ranch release names the breeder (Martin Ramos) but publishes no parentage.
- Chemistry, alpha acids, beta acids, cohumulone, total oil, myrcene, humulene, caryophyllene, farnesene not published. All chemistry fields: the Segal Ranch release published through the Washington Beer Blog gives no analytical values; Charles Faram and Yakima Valley Hops pages for Ramosa were not found.
