# Breweries index

Breweries index: every medal winning brewery, ranked by points.

## `header`

Where: top of the page.

- `title`: Breweries
- `lede`: Every medal winning brewery in the record, ranked by points (gold 3, silver 2, bronze 1). Narrow the list with Filters. ARR is an estimate (E).

## `table`

Where: above the table.

- `count`: {{count}} breweries with medals in view. Select a column header to sort.
- `deep_dive_pill`: Deep dive
